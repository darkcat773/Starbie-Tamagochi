# Starbie-Tamagochi

<img width="605" height="439" alt="image" src="https://github.com/user-attachments/assets/745ec124-a47a-4d1c-a7b1-25df1e4a1712" />

This project was made by following the Starbie tutorial on Hack Club: https://github.com/SharKingStudios/Starbie/blob/main/Week%201%20Guide.md

Starbie is a Tamagotchi-inspired virtual pet! The pet wanders around the screen, and it can sleep, play, eat, and respond to being petted. 

The user can tilt the device to move the selector on the radial menu and can press the left button to select the action. The right button allows the user to view the pet's status. Additionally, shaking the device triggers a different pet reaction as well!

Unlike the tutorial, the heart design is inspired by my OC, and every design(the hearts, soundwave, and patch) was drawn by me!
